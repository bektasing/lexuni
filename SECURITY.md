# Security Policy

## Reporting a vulnerability

Please do not disclose sensitive security issues in a public issue.

Use the repository's **Security** tab to open a private GitHub security advisory when that option is available. Include a concise description, reproduction steps, affected versions or browsers, and the potential impact. Do not attach real Lexuni backups or private vocabulary unless the maintainer explicitly requests a safely redacted example.

If private advisories are unavailable, contact the maintainer through a private channel listed on their [website](https://hamzabektas.xyz) and avoid sharing exploit details publicly until the issue has been reviewed.

The maintainer will acknowledge the report and coordinate next steps as availability permits.
